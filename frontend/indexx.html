Mathematical Formulation

Traveling Tournament Problem (TTP)

1. Total Travel Distance

f1(S) = ∑t=0n−1 (∑r=0R−1 travelt,r + return_homet)

Tracks each team's location throughout the season.

• Away games: travel from current location to opponent's stadium.

• Home games: return home first if currently away.

• End of season: return to home stadium.

Complexity: O(n3)

2. Rest Imbalance

f2(S) = ∑m∈matches |days_since_last(home) − days_since_last(away)|

Measures fairness of recovery time between opponents.

• Lower values = more equitable rest periods.

Complexity: O(n2)

3. Away Streak Violations

f3(S) = ∑t=0n−1 ∑r=0R−1 max(0, consecutive_awayt,r − 2)

Counts rounds where teams exceed 2 consecutive away games.

• Each round beyond the limit counts as one violation.

Complexity: O(n2)

4. Derby Blackout Penalty

f4(S) = ∑r∈blackout ∑(h,a)∈round r I({h,a} ∈ derbies)

Penalizes high-priority matches in unfavorable rounds (first 2, last 1).

Complexity: O(n2)

Combined Objective

F(S) = w1 f1(S) + w2 f2(S) + w3 f3(S) + w4 f4(S)

w1 = 1.0 (travel in km)

w2 = 0.01 (rest imbalance)

w3 = 5000.0 (away streak violations)

w4 = 3000.0 (derby violations)

Overall Complexity: O(n3)
